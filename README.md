# Chatty Creator Studio — Krea Potato

Standalone experimental Krea provider for Chatty Creator Studio.

## v0.1
- Krea OAuth (authorization code + PKCE + dynamic client registration)
- live `list_models`
- live `get_model_schema`
- image/video generation through Krea MCP
- async job IDs + `get_job` recovery
- iPhone-first UI
- noindex

This project intentionally stays separate from the existing WebDAW and Audio UI potatoes.
